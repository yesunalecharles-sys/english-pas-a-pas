# English Pas à Pas

Jeux d'anglais pour débutants francophones : quiz de vocabulaire, paires, écoute et construction de phrases, avec points, niveaux et étoiles.

L'application tient dans un seul fichier (`index.html`) et fonctionne dans le navigateur, sans installation. La progression est enregistrée sur l'appareil de chaque joueur.
